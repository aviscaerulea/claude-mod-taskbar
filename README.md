# task-bar
[![日本語](https://img.shields.io/badge/lang-日本語-red)](README.md)
[![English](https://img.shields.io/badge/lang-English-blue)](README.en.md)
[![License](https://img.shields.io/github/license/aviscaerulea/claude-mod-taskbar)](LICENSE)

Claude Code が作業の手順と進み具合を、ターミナルのプロンプトのすぐ上に細いバーで表示する mod です。
TodoWrite を持たないモデルでも、いま何の作業がどこまで進んだかを一目で確かめられます。

```
認証機能の実装：テストを書く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━▶···································· Tasks 2/5 40% 0:03:12
```

## 機能

- 進捗バー：Claude が手順リストを更新したとき、完了した手順の割合を件数と百分率つきのバーで表示する
- 滑らかな進み方：実行中の手順の区間を時間とともに少しずつ伸ばし、手順が完了したら次の位置まで約 1 秒で進める
- 経過時間：バーの右端に、計画の開始からの時間を表示し、全手順の完了か作業の中断で止める
- いまの手順：バーの上に、作業の題名と実行中の手順を表示する
- 計画の催促：Claude が手順リストを作らずに作業を始めたとき、手順リストを作るよう Claude に促す
- 完了の補完：Claude が最後の手順を完了にしないまま回答を終えたとき、残りの手順を完了として扱う
- 自動の後片付け：全手順が完了したとき、20 秒後か次のプロンプトを送った時点でバーを消す

## インストール

### 動作要件

- Claude Code の mod（フックモジュールのプラグイン）に対応した版（`v2.1.319` で動作を確認）
- ターミナル版の Claude Code

### 手順

Claude Code のプロンプトで次を実行します。

```
/plugin install task-bar --marketplace aviscaerulea/claude-mod-taskbar
```

マーケットプレイスの追加を聞かれたら `y` を選びます。
次にインストール先として user を選びます。

シェルから入れる場合は次を実行します。

```
claude plugin install task-bar --marketplace aviscaerulea/claude-mod-taskbar
```

## 使い方

インストール後は操作は要りません。
2 つ以上の手順がある作業を頼むと、Claude が手順リストを作ってバーが現れ、手順が終わるたびに進みます。

## 制限事項

- バーはターミナル版だけに表示し、デスクトップアプリや IDE 拡張には表示しない
- バーは Claude が手順リストを更新したときだけ変わるため、プロンプトの送信後に新しいバーが出るまで少し待つことがある
- Claude が質問のために作業の途中で回答を終えた場合も、バーは 100% になる
- 手順リストを持つのはメインの会話だけで、サブエージェントの作業はバーに出ない
- 他のプラグインが先にシステムプロンプトを組み立てる環境では、手順リストを作る指示が Claude に届かない
  - その場合は作業中の催促だけで手順リストの作成を促す
- バーの右端の `[-]` で折りたたむと、開き直すまでバーが見えなくなる
